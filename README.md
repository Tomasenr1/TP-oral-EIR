## Patrón y Modelo Adoptado

**Patrón:** Intraindustrial  
**Modelo Teórico:** Competencia Monopolística (Krugman) + Firmas Heterogéneas (Melitz)

**Modelos Descartados:**
- Ricardo: Predice comercio interindustrial por diferencias tecnológicas (ambas potencias manufactureras similares)
- Heckscher-Ohlin: Predice especialización por dotación de factores (ambas intensivas en capital y trabajo calificado)
